FAQ

Common questions

What happens if a user needs the raw password?

Policy decides. Credentials can be fully vaulted (user never sees them, rotation is automatic) or revealable with approval and logging for defined roles.

How do I secure legacy applications with MFA?

Put the second factor around the application instead of inside it. For web apps with a basic login page, the user signs in to IamLogic with MFA and the browser plugin fills in the app's own login, with the password rotated after use. Apps that can't authenticate at all can sit behind a reverse proxy that enforces MFA, and Kerberos apps can get push-based 2FA at the domain controller. None of these needs changes to the application. Read more on MFA for legacy applications.
